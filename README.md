
# Industrial AI - Smart Machine Identification & Predictive Maintenance

## Project Overview
An AI-powered industrial machine health monitoring and predictive maintenance platform.

The system aims to identify machines, analyze sensor data, detect anomalies, predict failures, estimate Remaining Useful Life (RUL), and provide maintenance assistance.

## Technologies
- Python
- JavaScript
- Django
- PostgreSQL
- OpenCV
- Scikit-learn
- XGBoost
- PyTorch
- SHAP
- FAISS
- Ollama

## AI Components
1. Machine Identification (OCR)
2. Failure Prediction
3. Anomaly Detection
4. Remaining Useful Life (RUL) Prediction
5. Explainable AI (SHAP)
6. RAG-based Maintenance Assistant

## Datasets
- UCI Hydraulic Systems
- NASA C-MAPSS (FD001)
- SKAB Anomaly Benchmark

## Project Structure
- data/       : Datasets
- notebooks/  : Data analysis and experiments
- models/     : Trained AI models
- src/        : AI source code
- webapp/     : Django application
- tests/      : Testing
- docs/       : Documentation
